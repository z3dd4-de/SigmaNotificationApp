Hilfe

1. Voraussetzungen

  • Sigma Docking Station TL2012

  • Sigma Sport Tacho xx.12*

  • Windows 10/11 64bit

  • Empfohlen: BikeDB 2026

* Aktuell werden BC12.12, BC16.12 und BC16.12 STS unterstützt

Es sollten alle Tachos der Topline 2009/2012-Reihe unterstützt werden. Wer einen anderen davon zum Laufen bekommt (siehe Github-Link in den Quellen), kann mir gerne die ID mitteilen, damit ich ihn allgemein verfügbar machen kann (siehe bekannte Tacho-IDs).


Leere Zeilen werden als „0“ gespeichert.



2. Installation

ZIP-Installationspaket von Github herunterladen, an beliebigen Ort entpacken.

„SigmaNotificationApp.exe“ starten, nach Bedarf Link z.B. auf dem Desktop anlegen.

Die installierte Version kann in BikeDB 2026 verknüpft werden und dort aus dem Menü heraus gestartet werden.



3. Verwendung

Die Anwendung starten, wenn die Sigma Docking Station angeschlossen ist. Tacho mit Fahrdaten einlegen. Sobald die Meldung erscheint, dass ein Tacho erkannt wurde, können die Daten importiert werden.




Entweder im Menü Tacho → Auslesen drücken oder auf das Tacho-Symbol klicken.

Jetzt sollten alle Felder mit den verfügbaren Daten befüllt worden sein (abhängig vom verwendeten Tachotyp).

Diese Daten können durch Klicken des „Speichern“-Button gesichert werden. Der Speicherort wird unter Menü → Einstellungen definiert.



Die eigentliche Aufgabe dieser Anwendung ist nur das Auslesen der Tachodaten. Um sie sinnvoll verwenden zu können, wird empfohlen, dass die BikeDB 2026 zur Verwaltung der Fahrraddaten benutzt wird. Dies ist eine mächtige Verwaltungssoftware für alles mögliche: verschiedene Fahrräder, Strecken, Fahrten, etc.



Es können ohne einen angeschlossenen Tacho auch manuelle Dateien erstellt werden: einfach alle Daten eintragen und die Datei speichern.



4. Speicher-Format

Die Anwendung erzeugt eine JSON-Datei „bikedata_JJJJMMTT-HHmm.json“. Der Zeitstempel ist die Uhrzeit, die im Datum mit Uhrzeit der Anwendung ausgewählt wurde. Man kann rückdatieren, wenn die Daten des Tachos später ausgelesen werden. Die Uhrzeit ist nicht wirklich wichtig, außer, man will z.B. mehrere Fahrten an einem Tag protokollieren, z.B. zuerst zur Arbeit, dann den Rückweg und abends eine richtige Tour. Die eigentliche Aufgabe dieser Anwendung ist allerdings die Verwendung innerhalb der BikeDB 2026, die ebenfalls auf meinem Github-Account verfügbar ist (siehe Quellen).

Alternativ kann man BikeDB Trax 2026 verwenden, die auf einem Smartphone dieselben Dateien erstellt. Hier bräuchte man weder einen Sigma Tachometer, noch diese Anwendung.



Wer eine eigene Lösung programmieren will, findet hier die C#-Klasse, die zum Serialisieren der JSON-Datei verwendet wird:

public class RideData

{

public string TachoName { get; set; }

public string BikeName { get; set; }

public DateTime Timestamp { get; set; }

public uint DistanceMeters { get; set; }

public uint TimeSeconds { get; set; }

public double MeanSpeedKmh { get; set; }

public double MaxSpeedKmh { get; set; }

public byte Cadence { get; set; }

public uint TripSectionDistanceMeters { get; set; }

public uint TripSectionTimeSeconds { get; set; }

public double MinAltitudeMeters { get; set; } = 0;

public double MaxAltitudeMeters { get; set; } = 0;


public double DistanceKm => DistanceMeters / 1000.0;

public TimeSpan Duration => TimeSpan.FromSeconds(TimeSeconds);

public TimeSpan TripSectionDuration => TimeSpan.FromSeconds(TripSectionTimeSeconds);

}


Eine funktionierende JSON-Datei sieht z.B. so aus:

{"TachoName":"BC 12.12","BikeName":"Carver X0-3","Timestamp":"2026-05-15T12:00:30","DistanceMeters":10740,"TimeSeconds":1825,"MeanSpeedKmh":21.18,"MaxSpeedKmh":40.25,"Cadence":0,"TripSectionDistanceMeters":0,"TripSectionTimeSeconds":0,"MinAltitudeMeters":0,"MaxAltitudeMeters":0,"DistanceKm":10.74,"Duration":"00:30:25","TripSectionDuration":"00:00:00"}


5. Userdaten

Die Anwendung speichert automatisch folgende Einstellungen:

  • Fensterposition und -größe

  • Status des Programms (Fenstermodus oder minimiert)

  • Zuletzt verwendeter Tacho (Name und Seriennummer)

  • Liste mit verfügbaren Fahrrädern

  • Zuordnung Tacho(Seriennummer) → Fahrrad

  • Sprache (Deutsch/Englisch)*

* Hinweis: die BikeDB2026 ist bisher nur in Deutsch verfügbar



6. Fahrräder und Tachos hinzufügen





In dem Formular Optionen → Einstellungen können Tachos und Fahrräder hinzugefügt werden. Außerdem wird hier der Speicherort für alle Dateien (*.JSON) festgelegt. Es wird empfohlen, das Verzeichnis, das die BikeDB verwendet, einzustellen. Die BikeDB 2026 legt automatisch ein Verzeichnis „SigmaNotificationApp“ an, das dann auch hier eingestellt werden sollte, wenn man beide Anwendung benutzt.

Das sind nicht unbedingt die Tachos, die über ihre Seriennummer erkannt werden, sondern nur die, die in den Dropdown-Menüs der Anwendung angezeigt werden.

Da die Anwendung natürlich nicht weiß, welche Fahrräder verwendet werden, sollte man sie hier möglichst präzise anlegen. „Hersteller Modellname Baujahr“ wird als Name empfohlen.



7. Verknüpfung von Tacho und Fahrrad





Wenn ein Tacho angeschlossen wurde, kann man diesen unter Optionen → Tacho mit Rad verknüpfen permanent zuordnen.

Auch hier drückt man erst das Tacho-Symbol und wartet, bis die Daten ausgelesen wurden. Dann kann man ein Fahrrad, das unter 6. angelegt wurde, verknüpfen.

Hier zählt nur die Seriennummer und es ist egal, was unter Modellname ausgewählt wurde. Der Modellname wird über USB übermittelt und muss nicht vorhanden sein (siehe 6.), um eine Verknüpfung herzustellen.
